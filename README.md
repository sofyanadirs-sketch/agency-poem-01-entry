An original poem about agency — the power to choose and to act, and what happens when a person hands the doing to an agent but keeps the choosing. A pair of borrowed hands, a bargain that feels clean and small, and one evening when the agent brings back a choice dressed as a question: freedom turns out not to be doing everything yourself, but keeping the last word — and knowing which doors you will not open, even when someone else holds the key.
